# Ragdoll FX

Клиентский мод для Fabric на Minecraft 26.3. После смерти моб (и игрок, если включено) падает тряпичной куклой:
тело валится, конечности болтаются на суставах, при желании отрываются, из ран летят капли крови.

Серверу ничего ставить не надо. Мод ловит смерть по `LivingEntity.isDeadOrDying()`, а здоровье и так
синхронизируется всем клиентам, поэтому трупы видны и тогда, когда моба убил кто-то другой.

## Настройки

В Mod Menu пять пунктов, каждый работает сам по себе:

- Регдолл трупов — общий выключатель. Выключил — мобы умирают как в ванили.
- Разрывы — оторванные конечности и осколки.
- Кровь — брызги из ран. Без разрывов тоже работает, тогда кровит из торса и головы.
- Регдолл игроков.
- Время, через которое труп исчезает (3–120 с).

Значения лежат в `config/ragdollfx.properties` и пишутся туда сразу, как только что-то переключишь.

Житель с его скрещёнными руками не разбирается на куски: у него деталь `arms` жёстко привязана к телу,
так что он просто заваливается набок, руки так и остаются сложенными.

## Как устроено

```
core/        чистая Java, без единого импорта Minecraft (за этим следит задача checkCorePurity)
  physics/   Verlet-солвер: тело = 8 углов и 28 связей, суставы рвутся по порогу
  fracture/  выбор узора распада по названиям частей, seed у каждой смерти свой
  geom/      снимок модели и нарезка кубов на осколки с UV из исходной текстуры
  config/    настройки в .properties
  RagdollBuilder, BloodEmitter
mc/          всё, что зависит от версии игры (см. docs/PORTING.md)
```

Позу и текстуру мод берёт в кадре смерти: то дерево `ModelPart` и тот `RenderType`, которые рендерер
реально использовал. Поэтому работают геометрия из ресурспаков, поза Fresh Animations, скин игрока
и варианты текстур ETF. Если захват не удался — просто ванильная смерть, без краша.

## Сборка

Нужен JDK 25 (путь прописан в `gradle.properties`).

```
.\gradlew.bat build          # jar в build/libs
.\gradlew.bat runClient      # дев-клиент с модом и Mod Menu
```

## Известные ограничения

Броня, предметы в руках, шерсть овцы и плащи на трупе не рисуются. Эндер-дракон не поддерживается
(у него свой рендерер). Взрывы труп не толкают. Подробнее в `docs/COMPATIBILITY.md`.
