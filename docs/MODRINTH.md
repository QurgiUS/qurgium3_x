# Публикация на Modrinth

Проверить ДО загрузки (правила меняются — читать актуальные: modrinth.com/legal/rules и docs.modrinth.com):
- [ ] Ни кода, ни ассетов, ни скриншотов Physics Mod в проекте нет. Physics Mod — только визуальный референс поведения. Код и алгоритмы здесь написаны с нуля.
- [ ] Название и описание не намекают на связь с Physics Mod / Haubna («inspired by» допустимо, но не используйте их брендинг и логотип).
- [ ] Лицензия MIT указана в проекте и в jar.
- [ ] Иконка — своя.
- [ ] Описание честное: клиентский мод, требует Fabric API, опционально Mod Menu; список ограничений из COMPATIBILITY.md.
- [ ] Если правила Modrinth требуют раскрывать использование ИИ при создании — раскрыть. Автор несёт ответственность за код: прочитать, протестировать, понимать его.
- [ ] Gore: кровь — отдельная опциональная галочка, по умолчанию выключена (дефолт: регдолл + разрывы, кровь выкл).
- [ ] Зависимости в метаданных: fabric-api (required), modmenu (optional).
